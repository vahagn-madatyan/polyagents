<objective>
Add slug retry with exponential backoff for unmapped games and market tag validation to ensure slug_table only contains tradable markets.

Purpose: Unmapped slugs are currently logged and permanently discarded — games that fail initial lookup due to timing (Gamma API propagation delay) are never retried. Market tags with empty token IDs silently enter slug_table and cause CLOB API errors downstream. This closes requirement MKT-02.
Output: Updated gamma.py with retry_unmapped_slugs(), _validate_market_tag(), and build_slug_table() validation; updated sports.py calling retry after each slug table build/refresh; and tests proving all behaviors.
