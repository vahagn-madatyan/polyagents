<objective>
Build the SportsTrader orchestrator and wire it into the sports.py event loop. SportsTrader takes a game_id, game_state, and market_tag, runs SportsExecutor.analyze_game(), gates on confidence gap and budget, places a trade (or logs dry-run), and writes the PregameCache entry. The sports.py event loop is updated to call SportsTrader at two trigger points: (1) on slug table build/refresh for newly mapped games, and (2) on each loop iteration for cache-expired games. Real CLOB balance replaces the SPORTS_INITIAL_WALLET_USD placeholder.

Purpose: This plan completes the pre-game trading pipeline end-to-end. Without this, SportsExecutor and PregameCache sit unused. With this, the bot actively analyzes and trades pre-game markets.

Output: SportsTrader class, updated sports.py with active pre-game loop, new env vars in .env.example, full test coverage.
</objective>
