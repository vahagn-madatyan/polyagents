## Critical Integration Gaps

### 1. Period Transition Events Always Dropped (CRITICAL)

**Affects:** WS-06, TRD-02, TRD-03

`_emit_period_transition()` in `sports_ws.py` creates an event dict with keys `{type, state, old_period, new_period}` — no `game_id` key. But `handle_period_transition()` in `ingame_trader.py` reads `msg.get("game_id")`, which is always `None`, so it always returns early. Period transitions never trigger slow-path LLM re-analysis.

**Fix:** Add `"game_id": state.game_id` to the event dict in `_emit_period_transition()`.

### 2. In-Game Budget Gate Always Fails (CRITICAL)

**Affects:** TRD-02

`InGameTrader` calls `can_spend_sports(trade_amount, 0.0)` with hardcoded `wallet_balance=0.0` at lines 387 and 513. `BudgetCoordinator.can_spend_sports()` returns `False` when `wallet_balance < SPORTS_MIN_WALLET_USD` (default $50). Result: every in-game trade is blocked.

**Fix:** Pass actual wallet balance to `InGameTrader.__init__()` or fetch it at trade time.

### 3. should_halt_trading() Never Called (HIGH)

**Affects:** WS-07

The function exists, is tested (11 unit tests pass), but no production code path calls it. Games in Suspended/Postponed/Canceled/Forfeit states are processed as normal.

**Fix:** Gate on `should_halt_trading(game_state)` in both `InGameTrader._handle_score_change()` and `SportsTrader.run_pregame_analysis()`.

### 4. Unmapped Slug Retry Not Wired (MEDIUM)

**Affects:** MKT-02

`build_slug_table()` returns unmapped slugs, and `lookup_single_slug()` exists for retry. But `sports.py` logs the unmapped list and discards it.

**Fix:** Add retry loop in slug table refresh cycle using `lookup_single_slug()`.
