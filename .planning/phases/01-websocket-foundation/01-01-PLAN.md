    ```python
    class SportsWSConnector:
        WS_URL = "wss://sports-api.polymarket.com/ws"
    ```

    **__init__:**
    - `self._message_queue = queue.Queue(maxsize=1000)`
    - `self._game_states: dict[int, SportGameState] = {}`
    - `self._state_lock = threading.Lock()`
    - `self._last_message_at: float = 0.0`
    - `self._ws_app: websocket.WebSocketApp | None = None`
    - `self._running = False`
    - `self._reconnect_attempt = 0`
    - `self._watchdog_timer: threading.Timer | None = None`
    - `self._connection_started_at: float = 0.0`
    - Load env config using `_env_int` from `agents.application.executor`: `freeze_timeout`, `ended_game_ttl_minutes`
    - Load `log_level` from `os.getenv("SPORTS_WS_LOG_LEVEL", "changes")`
    - Import: `from agents.application.executor import _env_int`

    **_on_message(self, ws, raw):**
    - If `raw == "ping"`: `ws.send("pong")`, return immediately (do NOT update _last_message_at — per watchdog pitfall)
    - Parse JSON; on JSONDecodeError, log warning and return
    - Update `self._last_message_at = time.monotonic()`
    - Call `self._process_game_state(data)`
    - Log per log_level: "all" logs every message, "changes" logs only score/period changes, "minimal" logs nothing here

    **_process_game_state(self, data):**
    - Extract game_id from data
    - Under _state_lock: get existing state, capture old_period
    - Build new state via `_build_game_state(data)`
    - Under _state_lock: store `self._game_states[game_id] = new_state`
    - AFTER releasing lock: check period transition (old_period != new_period and old_period is not None)
    - If transition detected: log it, put `{"type": "period_transition", "state": new_state, "old_period": old_period, "new_period": new_state.period}` to queue
    - CRITICAL: Do NOT hold _state_lock while calling _message_queue.put() — deadlock risk per RESEARCH.md pitfall #4

    **_on_open(self, ws):**
    - `print(f"[sports_ws] event=connected url={self.WS_URL}")`
    - `self._connection_started_at = time.monotonic()`

    **_on_error(self, ws, error):**
    - `print(f"[sports_ws] event=error error={error}")`

    **_on_close(self, ws, close_status_code, close_msg):**
    - `print(f"[sports_ws] event=disconnected code={close_status_code}")`

    **Public accessors:**
    - `get_game_state(game_id: int) -> Optional[SportGameState]`: return copy under lock
    - `get_all_game_states() -> dict[int, SportGameState]`: return dict copy under lock
    - `get_message_queue() -> queue.Queue`: return self._message_queue
