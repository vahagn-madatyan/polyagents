<objective>
Fix the slug_table key type mismatch that makes InGameTrader a no-op in production.

Purpose: `build_slug_table()` returns `dict[str, list[SportsMarketTag]]` keyed by slug string (e.g. `"nba-lal-bos"`), but `InGameTrader.tick()` and `handle_period_transition()` call `slug_table.get(game_id)` with an integer game_id. Every market lookup returns `None` silently — no trades ever execute in production. Unit tests mask this by mocking slug_table as `{int: tag}`.
Output: Fixed InGameTrader that looks up by `current.slug` string, updated tests using production-shaped slug_table, and an integration test that verifies the market lookup actually succeeds.
</objective>
